# Foundations inventory and scope decisions

Task: F01. Audited: 2026-10-14. Scope: local repository evidence, not publication or external source re-verification.

Method: inspected metadata and recorded sources for the 53 related concepts, all six recipe definitions, selected displayed snippets with important abstraction boundaries, and the relevant content/locale/search/rendering infrastructure. Enumerated candidate files and validated their paths; did not read or execute every candidate snippet. This is an inventory of reusable inputs, not a new runtime correctness audit.

## Findings

The catalog maps to **33 Expand**, **15 New**, and **0 Reuse** articles. All 48 article IDs and slugs remain unchanged. No existing item meets the full Foundations article standard as an immediately reusable article: the collection consists of concise comparisons and recipes rather than long-form MDX articles with contextual citations and explanatory diagrams.

Classification is an editorial judgment based on the observed material:

- **Reuse:** an existing complete article could be published with only integration work. None qualifies.
- **Expand:** existing explanations or examples cover a substantial part of the planned mechanism; author the missing depth and platform coverage.
- **New:** only adjacent concepts exist, or the core mechanism has no dedicated treatment. Existing pieces may still illustrate a small part.

The registry contains 72 concepts and 6 recipes. Implementation-key counts are React Native 72, Flutter 0, Jetpack Compose 72, SwiftUI 0; these counts do not prove equal depth or runtime verification. The existing Vietnamese overlay has keys for 72/72 concepts and 6/6 recipes. Key presence is not a translation review and does not supply Vietnamese article bodies.

The material map below references 53 distinct concepts and all 6 recipes. Their snippet roots contain 412 TSX/Kotlin/shell files, including distinct Learn basic files where present; this is a reuse inventory, not a count of completed article examples. No content-specific explanatory SVG/image collection or existing MDX article was found in the audited content/public paths; the public SVGs are starter assets.

- Use complete English/Vietnamese MDX article bodies. Existing `content/locales/vi.ts` and its imported modules are concept/recipe/roadmap overlays, not a `content/locales/vi/` article directory.

## Reusable assets and their limits

Read displayed regions before choosing an example. A `production` filename is a stage label, not proof of a complete production subsystem. Imports, declarations, and verification fixtures outside display regions are compilation context.

- [React Native restoration production](../content/snippets/state-restoration/react-native/production.tsx) loads a profile from a route ID. It does not implement navigation-state persistence or durable draft storage.
- [Kotlin restoration production](../content/snippets/state-restoration/kotlin/production.kt) reads a SavedStateHandle ID and observes repository state. It does not implement the repository or prove device-level process restoration.
- [React Native refresh-token recipe](../content/snippets/recipes/refresh-token/react-native/main.tsx) coordinates concurrent GET refresh and one retry. It is not write idempotency or a full OAuth flow.
- [Kotlin secure-storage recipe](../content/snippets/recipes/secure-storage/kotlin/main.kt) declares a CredentialStore interface and a Keystore intent. It does not implement encryption; never present the contract as cryptographic evidence.
- [React Native notification basic](../content/snippets/android-notifications/react-native/basic.tsx) calls an injected notifier. It does not implement native modules or remote push registration.

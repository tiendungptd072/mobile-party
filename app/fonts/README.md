# Geist fonts

Unmodified variable WOFF2 fonts from the official [Geist v1.7.2 release](https://github.com/vercel/geist-font/releases/tag/v1.7.2).

- `geist-sans.woff2`: `geist-font/Geist/webfonts/Geist[wght].woff2`
- `geist-mono.woff2`: `geist-font/GeistMono/webfonts/GeistMono[wght].woff2`

Both fonts support weights 100–900. They are bundled locally so builds do not need Google Fonts access. The original SIL Open Font License is included in `OFL.txt`.

Source archive: `geist-font-v1.7.2.zip`, SHA-256 `7fc800d2ac6b92844895196e5041aca55d814c15db70c44f79b3b83ab82b04e2`.
